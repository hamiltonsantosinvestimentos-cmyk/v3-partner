Repositório e Dependências

Clone, instalação e primeiro start

1

Clonar ou atualizar o repositório

# Se ainda não tem o repositório: git clone https://github.com/hamiltonsantosinvestimentos-cmyk/v3-partner.git cd v3-partner # Se já tem o repositório localmente: cd caminho/para/v3-partner git pull origin main
2

Instalar as dependências

npm install

Instala Next.js 16, Supabase SSR, Anthropic SDK e todas as dependências do projeto.

3

Abrir o Claude Code no projeto

# No terminal, dentro da pasta do projeto: claude

O Claude já conhece toda a arquitetura pelo CLAUDE.md do projeto. Descreva o que quer construir — ele executa com autonomia total.

4

Iniciar o servidor de desenvolvimento

npm run dev

Acessa em http://localhost:3000

Importante: O arquivo .env.local não sobe para o GitHub (gitignored). Deve ser criado manualmente em cada máquina conforme a página 3 deste guia.

Variáveis de Ambiente

Criar o arquivo .env.local na raiz do projeto

Variável Onde obter
NEXT_PUBLIC_SUPABASE_URL Supabase Dashboard → Project Settings → API → Project URL OBRIGATÓRIO
NEXT_PUBLIC_SUPABASE_ANON_KEY Supabase Dashboard → Project Settings → API → anon public OBRIGATÓRIO
SUPABASE_SERVICE_ROLE_KEY Supabase Dashboard → Project Settings → API → service_role OBRIGATÓRIO
ANTHROPIC_API_KEY console.anthropic.com → API Keys OBRIGATÓRIO
RESEND_API_KEY resend.com → API Keys (plano gratuito disponível) OBRIGATÓRIO
CLICKSIGN_ACCESS_TOKEN app.clicksign.com → Configurações → Tokens de API OPCIONAL
CLICKSIGN_WEBHOOK_SECRET Definido ao cadastrar o webhook no ClickSign OPCIONAL
NEXT_PUBLIC_CREATIVE_ENGINE_URL URL do serviço Railway após deploy (ver pág. 4) OPCIONAL

Exemplo de .env.local completo

NEXT_PUBLIC_SUPABASE_URL=https://xyzxyzxyz.supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci... SUPABASE_SERVICE_ROLE_KEY=eyJhbGci... ANTHROPIC_API_KEY=sk-ant-api03-... RESEND_API_KEY=re_xxxxxxxxxxxx CLICKSIGN_ACCESS_TOKEN=seu_token_aqui CLICKSIGN_BASE_URL=https://app.clicksign.com CLICKSIGN_WEBHOOK_SECRET=secret_aqui NEXT_PUBLIC_CREATIVE_ENGINE_URL=https://engine.railway.app

Banco de Dados e Deploy

Migração Supabase + Creative Engine no Railway

5

Rodar o schema no Supabase

No Supabase Dashboard → SQL Editor, abrir e executar o arquivo:

v3-partner/supabase-schema-criativos.sql

Cria as tabelas creative_jobs e creative_files e adiciona colunas em ma_deals. Tudo com IF NOT EXISTS — não quebra dados existentes.

6

Deploy do Creative Engine no Railway

Pasta: services/creative-engine/ — Node.js + Puppeteer para geração real de PDF e PNG.

# No Railway (railway.app): 1. Novo projeto → Deploy from GitHub repo 2. Selecionar pasta: services/creative-engine 3. Adicionar variáveis de ambiente: SUPABASE_URL = (mesma do .env.local) SUPABASE_SERVICE_ROLE_KEY = (mesma do .env.local) PORT = 3001 4. Copiar a URL gerada → colar em NEXT_PUBLIC_CREATIVE_ENGINE_URL
