Resumo Executivo

⚠
Erro observado: Ao clicar em "Validar com FORJA" na tela /mesa-ma, a UI exibia:
"Falha na validação: HTTP 504"

O erro 504 (Gateway Timeout) significa que a função serverless no Vercel foi encerrada pelo servidor antes de completar a resposta. Foram identificados dois problemas independentes, um em cada endpoint do módulo M&A, ambos relacionados ao tempo de resposta da API da Anthropic.

Causa Raiz — 2 Problemas Identificados

Arquivo Problema Impacto Severidade
api/ma/forja-validate/route.ts max_tokens: 4096 — excessivo para um JSON de validação. A Anthropic gera a resposta token por token; 4096 tokens levam 30–50 segundos. Chamada excede 60s → Vercel retorna 504 antes de completar. Crítico
api/ma/validacao-documental/route.ts Ausência de export const maxDuration. Sem essa declaração, o Vercel aplica o timeout padrão de 10 segundos para funções serverless. Qualquer chamada ao Anthropic (≥15s) resulta em 504 imediato. Crítico

Detalhamento Técnico — Como o Timeout Ocorre

Funções serverless no Vercel têm um limite de duração máxima. Sem a declaração explícita, o padrão é 10 segundos. A chamada à API da Anthropic para geração de texto leva em média:

ParâmetroValor anteriorTempo médio estimado
max_tokens409630–50 segundos
max_tokens150010–18 segundos
maxDuration Vercel (padrão)10s (sem declaração)Mata a função antes de resposta
maxDuration Vercel (declarado)60sPermite resposta completa
